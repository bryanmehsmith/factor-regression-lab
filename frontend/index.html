When an asset beats the market, is that skill or is it factor exposure? Regress its excess return on the Fama-French factors: the intercept is what the factors cannot explain, and the standard errors decide whether that intercept means anything.

Why alpha only means something relative to a model

"This fund returned 14% a year" is not a finding. The question is always 14% compared to what, and the honest comparison is not a single index but a set of systematic risks the investor could have taken deliberately and cheaply. That comparison is a regression: take an asset's return in excess of the risk-free rate, and explain it with the returns of portfolios built to capture known systematic exposures.

Technical detail

excess_return = alpha + b1*(Mkt-RF) + b2*SMB + b3*HML + ... + residual. Each beta says how much of the asset's behaviour is that exposure. Alpha, the intercept, is the average monthly return the factors fail to explain, and it is defined entirely by which factors sit on the right-hand side: add a factor that genuinely drives the asset and alpha shrinks, since the "skill" was an exposure not yet named. CAPM is the market alone; FF3 adds size (SMB) and value (HML); FF5 adds profitability (RMW) and investment (CMA); FF5+Mom adds momentum. Mkt-RF, SMB and HML all come from the 5-factor file rather than the standalone 3-factor file (which defines SMB slightly differently and starts in a different year), keeping FF3 a genuine subset of FF5 over an identical sample, which is what makes the nested test below valid.

Why the standard error decides the answer

Getting alpha is easy. Deciding whether it is distinguishable from zero is where the work is, and it depends on assumptions about the residuals that are rarely stated out loud. The point estimate never changes; what changes is the standard error, and with it the t-statistic.

Technical detail

Classical (OLS) assumes residuals are independent with constant variance; asset returns violate both. White (HC1) drops constant variance, accounting for volatility clustering. Newey-West (HAC) additionally allows residuals to be correlated across months, which matters most: positive residual autocorrelation makes several hundred monthly observations behave like far fewer independent ones, so classical errors understate uncertainty and inflate the t-statistic. An alpha whose t-statistic clears 1.96 under classical errors but not under Newey-West was never really significant. The HAC lag length is a judgment call exposed as a control below rather than hidden; the common default is floor(4 * (n/100)^(2/9)), but nothing makes it correct.

5. Can the individual betas be trusted?

Correlated factors inflate each other's standard errors. A high VIF does not bias the estimates or spoil the fit; it means that particular coefficient is hard to pin down, which is how a model can be jointly strong with no individually significant factor.
